## Convenciones de Nomenclatura

### Tipos de Documentos
- `*_EXECUTIVE_SUMMARY.md` - Resúmenes para management
- `*_IMPLEMENTATION*.md` - Reportes de implementación
- `*_FIX*.md` - Correcciones de bugs
- `*_TEST*.md` - Reportes de testing
- `*_AUDIT*.md` - Auditorías técnicas
- `*_GUIDE*.md` - Guías de desarrollo
- `FASE_*.md` - Documentos de hitos/fases

### Estructura de Trimestres
```
docs/reports/[categoria]/YYYY-Q[1-4]/
```

Ejemplo: `docs/reports/implementation/2025-Q4/`
